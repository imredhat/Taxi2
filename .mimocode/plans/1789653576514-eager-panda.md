### 3. API Key Setup Required
In `app.json`, replace `"__YOUR_NESHAN_API_KEY__"` with your key from [platform.neshan.org](https://platform.neshan.org/panel/login).

### 4. Native Build Requirement
Before building for Android/iOS:
```bash
# Android: add Maven repo to android/build.gradle
maven { url "https://maven.neshan.org/artifactory/public-maven" }
# Add to android/app/src/main/AndroidManifest.xml:
<meta-data android:name="org.neshan.MAPS_API_KEY" android:value="YOUR_KEY"/>

# iOS: after adding the key to app.json, run:
cd ios && pod install
```
